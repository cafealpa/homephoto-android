# HomePhoto Android 1.2.1

## 사진 탭 수정

- 사진을 모두 불러오기 전에도 서버의 전체 연·월 목록을 표시합니다.
- 원하는 월을 선택하면 해당 월의 사진을 바로 조회합니다. 여러 해의 같은 달을 구분하도록 연도도 표시합니다.
- 전체 보기에서 스크롤할 때 이전 사진을 계속 불러오지 못하던 문제를 수정했습니다.
- 새로고침 도중 이전 요청의 응답이 섞이지 않도록 처리했습니다.
- 월 목록 조회 실패 안내와 재시도를 지원합니다.

## 포함된 기능과 업데이트

- 1.2.0의 내부·외부 서버 자동 전환 기능을 포함합니다. Wi-Fi는 내부 우선, 그 외 네트워크는 외부 우선이며 연결 실패 시 다른 주소를 사용합니다.
- 기존 정식 버전과 동일한 키로 서명한 APK입니다. versionCode는 4이며 앱 설정의 새 버전 확인 또는 첨부 APK로 업데이트할 수 있습니다.
- 단위 테스트 47개와 정식 APK 빌드로 검증합니다. 실제 휴대폰의 설치·화면 동작은 별도 확인이 필요합니다.
