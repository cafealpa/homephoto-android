# HomePhoto Android 1.3.0

## 6가지 테마와 노멀·다크 모드

- 설정 → 화면 디자인에서 피치 크림, 세이지 가든, 클라우드 블루, 라벤더 미스트, 샌드 라테, 실버 모노를 선택할 수 있습니다.
- 색상과 별도로 시스템 설정 따르기 / 노멀 / 다크를 선택할 수 있습니다.
- 선택은 즉시 반영되고 앱을 다시 실행해도 유지됩니다. 기본은 피치 크림 + 시스템 설정 따르기입니다.
- 카드, 버튼, 선택 영역, 오류 표시와 시스템 바가 함께 바뀝니다. 사진과 전체화면 감상의 검정 배경은 유지됩니다.
- 기존 하트 사진 앱 아이콘과 연도·월 필터 개선을 포함합니다.

## 홈에서 바로 만나는 추억

- 과거 이맘때, 다시 꺼내 보는 하루, 최근 일주일 사진을 카드로 보여주고 바로 감상할 수 있습니다.
- 마음에 드는 추억은 사진과 순서를 골라 앨범으로 간직할 수 있습니다.
- 새 추억 기능은 해당 API를 지원하는 HomePhoto 서버가 필요합니다. 구형 서버에서도 최근 사진은 계속 볼 수 있습니다.
- 이 릴리스는 Android 앱 배포이며 운영 서버를 교체하지 않습니다.

## 업데이트와 검증

- versionCode 6, versionName 1.3.0. 기존 정식 버전과 같은 서명키를 사용합니다.
- APK 및 SHA-256 파일을 함께 제공합니다. 앱 설정의 업데이트 확인에서도 받을 수 있습니다.
- 단위 테스트 56개, 에뮬레이터 테스트 2개가 통과했습니다. 6×3개 설정 저장 조합과 기존 연결 설정 보존을 확인했습니다.
- Android 14 에뮬레이터에서 12개 팔레트 표시, 강제 종료 후 선택 유지, 시스템 모드 전환을 확인했습니다.
- 기존 정식 1.2.2에서 1.3.0으로 덮어쓰기 설치에 성공했고 두 APK의 서명 인증서가 일치합니다.
- 정식 APK 빌드와 release 필수 lint가 통과했습니다.
- 실제 휴대폰과 운영 서버 조합에서의 화면·설치 동작은 별도 확인 대상입니다.
