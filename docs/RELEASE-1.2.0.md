# HomePhoto Android 1.2.0

- 설정에서 내부·외부 서버 주소를 따로 저장할 수 있습니다.
- Wi-Fi에서는 내부 서버를 먼저 사용하고 접속 실패 시 외부 서버로 전환합니다. 그 외 네트워크에서는 외부 서버를 먼저 사용합니다.
- 사진 목록, 썸네일, 전체화면 보기, 백업 및 연결 테스트에 같은 주소 선택 규칙을 적용합니다.
- 접속 실패한 주소는 30초 동안 후순위로 두며 네트워크가 바뀌면 우선순위를 다시 판단합니다.
- 인증 오류 등 서버의 HTTP 오류 응답은 다른 주소로 재시도하지 않습니다. 이미 전송된 저장·업로드 요청도 중복 전송하지 않습니다.
- 기존 서버 주소는 외부 주소로 유지됩니다. 주소는 http:// 또는 https://를 포함해 입력하세요. 내부·외부 중 하나만 입력해도 사용할 수 있습니다.

versionCode는 3이며 기존 1.1.0 정식 배포 키로 서명합니다. 앱 설정의 새 버전 확인 또는 첨부 APK로 업데이트할 수 있습니다.

실제 휴대폰의 Wi-Fi·모바일 데이터 전환과 설치는 별도 확인이 필요합니다.
