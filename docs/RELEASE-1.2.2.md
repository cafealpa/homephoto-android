# HomePhoto Android 1.2.2

## 주요 변경

- 사진 필터의 연도와 월 선택을 분리해 원하는 기간을 쉽게 찾을 수 있습니다.
- 앱 아이콘을 하트와 사진을 결합한 디자인으로 교체했습니다.
- 1.2.1의 전체 월 목록 조회, 이전 사진 자동 로딩, 요청 간 응답 혼합 방지와 내부·외부 서버 자동 전환 기능을 포함합니다.

## 업데이트

- versionCode는 5이며 기존 정식 APK와 동일한 키로 서명합니다.
- 앱 설정의 새 버전 확인 또는 첨부된 `homephoto-android-5.apk`로 업데이트할 수 있습니다.
- 기존 정식 앱 위에 업데이트 설치하면 설정과 백업 이력을 유지합니다. 앱을 삭제할 필요가 없습니다.
- 단위 테스트 50개, 정식 APK 빌드와 서명 검증을 통과했습니다. 이전 공개 1.2.1 APK와 서명 인증서가 일치합니다.
- APK SHA-256: `3ba6e76ab9840adc38f3e5ab250d7b8d4bafa2c74dd86dc713c40a951fafe417`.
- 실제 휴대폰 설치/화면 동작은 별도 검증 범위입니다.
