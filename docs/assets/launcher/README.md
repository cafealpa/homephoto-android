# HomePhoto 앱 아이콘

사용자가 선택한 02번 시안: 주황 배경, 겹친 크림색 사진 두 장과 산호색 하트.

- 생성 도구: 내장 image_gen (투명 배경).
- 생성 프롬프트: 승인된 02번의 사진 두 장, 기울기, 크림색 종이와 산호색 하트를 유지하고, 주황 타일과 번호 및 다른 시안을 제거한다. 실제 투명 배경의 정사각형 캔버스 중앙 62% 안에 사진을 배치한다. 얇은 종이 그림자만 유지하고 텍스트와 추가 기호를 넣지 않는다.
- 원본: heart-photos-source.png. 생성 원본의 알파 채널을 보존한다.
- 적응형 아이콘: 108dp 기준 주황 그라데이션 배경 + 432px xxxhdpi 전경. 전경을 원본 캔버스의 90% 크기로 배치해 마스크 여백을 확보한다.
- 테마 아이콘: 별도 단색 벡터로 사진 테두리와 하트를 표시한다.
- 일반/원형 mipmap: mdpi부터 xxxhdpi까지 48/72/96/144/192px PNG.
- preview.png 및 preview_round.png는 적응형 108dp 레이어의 중앙 72dp 영역을 기준으로 만든 모양 확인용 미리보기다. 실제 런처의 마스크와 움직임은 기기에 따라 달라진다.
